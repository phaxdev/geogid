# GEOGID 🗺️

> Интерактивный гео-навигатор и цифровой путеводитель по знаковым природным и культурным локациям России.

![GEOGID Status](https://img.shields.io/badge/Status-Active-blue?style=for-the-badge)
![Live Demo](https://img.shields.io/badge/Demo-GitHub_Pages-emerald?style=for-the-badge)

## 🌟 Возможности

- **Интерактивная карта на базе Leaflet & CartoDB Dark:** Точные координаты и маркеры достопримечательностей по всей РФ.
- **Плавная навигация (FlyTo):** Мгновенный перелет камеры к выбранной локации при клике.
- **Фильтрация и категории:** Быстрый отбор по категориям (Горы, Природа, Культура, Архитектура) и текстовый поиск.
- **Карточки локаций:** Описание, координаты, рейтинги и фото.

## 🛠️ Стек

- React 18
- Leaflet.js (интерактивные векторные и растровые карты)
- TailwindCSS
- Lucide Icons
- Vite
